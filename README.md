# QuizGarden

Developed with VScode and Claude AI.

An All-In-One study companion that groups all your favourite apps and necessities into one, simple to use website with a gardening theme.

Features:
- A fun interactive game that quizzes you based on your notes and study material
- A question editor to create, edit or delete existing questions and answers.
- Pomodoro Timer
- Focus Mode that grows a plant (will be options) while the user studies. Plant fully grows in whatever timeframe the user sets, rather than delaying gratification for a much further goal
- Plant Gallery to view all acquired plants.
